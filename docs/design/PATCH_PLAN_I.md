# 시안 I 패치 계획

2026-11-28 시안 I로 확정. 매장에서 **지금 쓰고 있는 앱**이므로 작은 단계로 나눠 배포한다.
기준 시안: 휴대폰 `docs/design/mockups/I_*.html`, 태블릿 가로·PC `docs/design/mockups/wide/I_*.html`.

## 지킬 원칙 (모든 단계 공통)

1. **화면 모양만 바꾼다.** `web/engine.js`(`src/`) 계산, `web/gsync.js` 구글 시트 동기화, 저장 형식(localStorage 키, 시트 열)은 건드리지 않는다.
2. `web/app.js`가 쓰는 **id·class·data- 속성 훅은 지우거나 이름을 바꾸지 않는다.** 새 모양이 필요하면 클래스를 더하거나 CSS로 처리한다.
3. **달력은 월요일 시작을 유지한다.** 시안 I는 일요일 시작으로 그려져 있지만, 앱의 주차·주휴 계산(`weekIndex`, `dayIndex` 0=월)이 월요일 기준이다. 시안의 모양만 가져온다.
4. 휴대폰(390px), 태블릿 가로(1180px), PC(1440px) / 한국어·영어 / 라이트·다크 / 인쇄 / **잠긴 매장 기기(body.locked, 출퇴근만)** 모두에서 확인한다.
5. 이모지는 선 아이콘(SVG, stroke 1.8~2)으로 바꾼다. 새 문구는 `web/lang_web.js` 영어 번역을 같이 넣고 `node tools/i18n_scan.js`로 확인한다.
6. 단계마다 커밋 하나. 문제가 생기면 그 커밋만 되돌린다(`git revert`).
7. 화면이 바뀌면 사용 방법 가이드 스크린샷(`web/img/guide-*.webp`)도 다시 찍는다(마지막 단계에서 한 번에).

## 제미나이 검토 반영 (2026-11-28, 전문: `docs/design/reviews/patch_plan_I_gemini.md`)

공통
- `web/index.html` viewport에 `viewport-fit=cover`를 넣어야 아이폰 아래 안전 영역(`env(safe-area-inset-bottom)`)이 동작한다.
- z-index 순서: 메뉴 80 < 토스트 85 < 구글 모달 100 < 날짜 팝업 200 < 시트 900~920 < 출퇴근 팝업 1000 < 화면 보호기 3000.
- 새 넓은 화면 규칙은 반드시 `@media screen` 안에. 인쇄(명세서·점검표·계좌 안내판)가 밀리지 않게 한다.
- 메뉴를 위한 여백은 `body:not(.locked)`에만 준다(잠긴 매장 기기는 메뉴가 없다). `body.locked .tabs`를 이기는 `!important`를 쓰지 않는다(잠금이 뚫린다).
- 시안의 고정 색 대신 CSS 변수(`--card`, `--text`, `--muted`, `--line`, `--primary`)를 써서 다크 모드를 지킨다.
- 단계마다 `index.html`의 `?v=` 값을 올린다(매장 태블릿 캐시 갱신).
- 번역 점검은 `node tools/i18n_scan.js` 외에 브라우저에서 `AlbaLang.collect()`가 빈 배열인지도 본다.
- e2e에 큰 글자 모드(`가+`, body zoom), 인쇄, 360·768·1024·1300 폭, 알바생 0명, 모달 열림 상태를 더한다.

단계별로 확인된 사실
- 1단계: `i18n.js`는 `data-en`이 있는 요소의 내용을 통째로 바꾼다 → 아이콘을 넣으려면 글자를 `<span>`으로 감싸고 `data-en`을 span으로 옮긴다. 숨은 `.tab-guide` 버튼은 사용 방법 열기에 쓰이므로 남긴다. 위쪽 머리띠(`.app-header`: 관리자·알림·구글 저장·? 버튼)는 1단계에서 그대로 둔다(? 버튼 정리는 5단계). 220px 메뉴의 가게 이름은 `app.js` 수정이 필요하므로 5단계로 미룬다.
- 2단계: 비밀번호는 4자리 숫자가 아니라 최대 20자 문자열이다 → 키패드 시안을 그대로 쓰지 않는다. `#punchCloud`(구글 상태), 퇴근 확인 경고, 요청자 기기 안내, `#lockBtn` 글자를 덮어쓰는 `app.js`를 함께 고친다.
- 3단계: 주차 줄의 [이 주는 주휴 지급] 버튼(2-9), 식대 1회/2회(점심·저녁) 구분, `#pendingBox`·`#conflictBox`, `#rightViewSwitch` 훅, 명세서·카톡·PDF·엑셀 버튼 경로를 유지한다.
- 4단계: 실제 항목은 **41개·9개 분류**(시안·FEATURES의 38개는 틀림, FEATURES 고침). 입력 폼은 `buildChecklistForm()`. 저장은 체크/미체크 2상태이므로 [적합 | 점검 필요]도 2상태로. 20번 온도 자동 판정, `#chkDoc` 인쇄 유지.
- 5단계: `#cloudBtn`이 없으면 `renderCloudUi`가 멈춘다 → 지우지 말고 옮긴다. 가이드 본문의 "오른쪽 위 [?]" 문구도 고친다.
- 6단계: `pay.js`가 복사 버튼 글자를 덮어쓴다, `pay.html` CSP(`style-src self`)로 인라인 스타일 금지. `security-reviewer` 추가.
