# 시안 M 넓은 화면 버전 만들기

먼저 `docs/design/briefs/wide_common.md`를 읽고 그 규칙을 모두 따른다. 맡은 시안: **M**.
만들 파일: `docs/design/mockups/wide/M_Punch.html`, `M_Pay.html`, `M_Chk.html`, `M_QR.html`, `M_Set.html`

## 시안 M의 개성 (넓은 화면에서도 유지)
- 휴대폰 특징: 이번 달 시간을 크게 보여 주는 요약 대시보드, 파란 블록 달력(날짜 옆 점 = 식대, 위 출근·아래 퇴근), 아래 1~5주 표. 출퇴근은 '근무 중 / 출근 전' 묶음. 점검은 진행 도넛 + 분류 8개 타일. QR 화면에 손님 휴대폰 미리보기. 설정은 시간 끊기 상세(끊는 단위 5·10·15·30분·1시간, 출근 올림, 퇴근 내림, 지각·조기퇴근 봐주기, 자동 퇴근 시각)가 펼쳐져 있음.
- 넓은 화면 배치(대시보드형):
  - 근무·급여: 맨 위 숫자 카드 줄(이번 달 시간 120h / 근무 16일 / 식대 14회 / 줄 돈 숨김), 아래 왼쪽 달력, 오른쪽 1~5주 표(세로로 길게).
  - 출퇴근: 위 시계 줄, 아래 '근무 중' 열과 '출근 전' 열을 나란히(퇴근한 사람은 출근 전 열 아래).
  - 위생 점검: 왼쪽에 큰 진행 도넛 + 온도 + 8개 분류 타일(2열), 오른쪽에 선택한 분류(개인위생)의 항목 목록.
  - 설정: 왼쪽 설정 목록, 오른쪽 시간 끊기 상세 패널.
  - QR: 왼쪽 큰 QR + 계좌, 오른쪽 손님 휴대폰 미리보기(휴대폰 테두리 안에 손님 화면 모양).
