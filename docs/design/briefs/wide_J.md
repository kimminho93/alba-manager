## 시안 J의 개성 (넓은 화면에서도 유지)
- 휴대폰 특징: 주차 탭으로 주를 고르면 달력에서 그 주를 강조하고 아래에 요약 줄, 칸 안 ↑출근 ↓퇴근과 '식' 표시. 출퇴근은 2단계(1. 이름 고르기 → 2. 비밀번호 → 큰 버튼). 점검은 분류 칩 + 항목 카드마다 큰 O / X. 설정 맨 위 검색창.
- 넓은 화면 배치:
  - 출퇴근: 화면을 세 단으로 나눠 단계가 한눈에 보이게: [1. 이름 고르기 목록] → [2. 비밀번호 4칸 + 숫자 키패드] → [3. 큰 출근/퇴근 버튼과 기록될 시각]. 위에 시계.
  - 근무·급여: 위에 주차 탭(전체·1~5주차) 가로로, 가운데 달력(선택 주 강조), 오른쪽 320px 패널에 선택 주 요약 카드 + 줄 돈(숨김/보기) + 명세서·내보내기 버튼. 알바생은 맨 위 이름 칩으로 고른다.
  - 위생 점검: 분류 칩은 위에 가로로, 항목 카드는 2열 격자, 큰 O / X 유지. 오른쪽 위 온도·진행도.
  - 설정: 맨 위 넓은 검색창, 아래 설정 묶음들을 2열 카드로.
  - QR: 가운데 큰 QR, 아래 계좌와 큰 [계좌번호 복사].
