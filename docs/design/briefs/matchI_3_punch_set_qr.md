# 시안 I 맞추기 3 — 출퇴근 머리 줄, 설정, 계좌이체 QR

먼저 `docs/design/briefs/matchI_common.md`를 읽고 그 규칙을 모두 따른다.
기준: `docs/design/mockups/I_Punch.html`, `I_Set.html`, `I_QR.html` (넓은 화면은 `mockups/wide/` 같은 이름).

## 출퇴근 (I_Punch)
- 시안 머리 줄: 왼쪽 **가게 이름**("우리분식 본점", 없으면 "사장님 도우미"), 오른쪽 **[자물쇠 아이콘 관리자]** 하나. 공통 머리띠(로고·알림·구글 저장)는 이 화면에서 보이지 않는다.
  → `#lockBtn`을 이 자리에 보이게, 알림·구글 저장은 이 화면에서 숨긴다(다른 화면 머리 줄·⋯에 있음). 잠긴 매장 기기에서도 이 모양.
- 날짜(작게) → 큰 시계 → "이름을 누르고 비밀번호를 넣어요" + [모두 퇴근] → 이름 줄 → 아래 [계좌이체 QR][English]: 이미 비슷하다(유지).
- 구글 저장 상태(`#punchCloud`)는 시안에 없다 → 문제가 있을 때만 작은 한 줄로(지금 큰 빨간 상자는 시안과 다르다).

## 설정 (I_Set)
- 머리 줄 "설정" + 오른쪽 작은 "v1.7.1".
- 묶음: **매장·기기**(매장 정보, 구글 시트 저장, 관리자 비밀번호, 출퇴근 기기, 손님 계좌이체 QR) / **출퇴근**(시간 끊기, 알림음, 화면 보호기) /
  **급여·위생 기준**(최저시급·식사 시간대, 보건증 알림, 세금·4대보험 비율) / **앱**(언어·글자 크기·다크 모드, 사용 방법, 앱 정보·공유).
  줄마다 왼쪽 선 아이콘 + 제목, 오른쪽 현재 값 + ›.
- 지금 맨 위 "화면 [가+][달][EN]" 빠른 줄은 시안에 없다 → **앱 > 언어·글자 크기·다크 모드** 줄 안으로 옮긴다.
- 구글 시트 저장이 설정 줄로 들어간다(시안). `#cloudBtn` 동작(연결 창 열기)을 그 줄에서 부르게.
- 넓은 화면: `wide/I_Set.html`처럼 왼쪽 묶음 목록 + 오른쪽 상세.

## 계좌이체 QR (I_QR)
- 머리 줄 "계좌이체 QR" + 닫기(×), 가게 이름, 큰 QR, "카메라로 찍어 주세요", 작은 안내, 계좌 카드("예시은행 · 예금주 우리분식" / 큰 계좌번호 + [복사]), 아래 [계산대 안내판 인쇄].
- 지금은 [닫기]만 있다. 시안처럼 [복사]·[계산대 안내판 인쇄]를 넣는다(인쇄는 설정의 안내판 인쇄와 같은 동작). 잠긴 매장 기기에서는 인쇄 버튼을 숨긴다.
