# 넓은 화면(태블릿 가로·PC) 시안 — 공통 지시

## 배경
`docs/design/mockups/`에 있는 시안 I~M은 모두 휴대폰(390×844) 화면이다.
같은 시안을 **태블릿 가로(1180×820)와 PC(1440×900)**에서 어떻게 보이는지 보여 주는 넓은 화면 버전을 만든다.

## 먼저 읽을 것 (직접 열어서 읽는다)
- `CLAUDE.md` — "UI 방향", "근무시간 정리(급여 홈) 화면 필수 조건"
- `docs/design/README.md` — 색 기준값, 시안 요약표
- `docs/FEATURES.md` — 전체 기능 목록과 새 UI 배치표 (기능이 하나도 빠지면 안 된다)
- 맡은 시안의 휴대폰 파일 5장: `docs/design/mockups/<시안>_Punch.html`, `_Pay`, `_Chk`, `_QR`, `_Set`

## 만들 파일
`docs/design/mockups/wide/<시안>_Punch.html`, `<시안>_Pay.html`, `<시안>_Chk.html`, `<시안>_QR.html`, `<시안>_Set.html` (5장)
- 손님 화면(`_Cust`)은 손님 휴대폰에서만 열리므로 만들지 않는다.

## 넓은 화면 규칙
1. **휴대폰 화면을 늘린 모양이 아니다.** 옆 공간을 써서 배치를 다시 짠다. 예: 왼쪽에 목록·요약, 오른쪽에 달력·상세.
2. 하단 메뉴 4개(출퇴근 / 근무·급여 / 위생 점검 / 설정)는 **왼쪽 세로 메뉴**로 옮긴다.
   - 화면 폭 1300px 미만(태블릿 가로): 폭 88px, 아이콘 아래 글자.
   - 1300px 이상(PC): 폭 220px, 아이콘 옆 글자 + 맨 위 가게 이름.
   - 메뉴 링크는 같은 폴더의 같은 시안 파일로 이동한다(`<시안>_Pay.html` 등). QR 화면은 출퇴근 화면 버튼에서 연다.
3. 페이지는 `width:100%; height:100vh`로 채우고, 1024px~1600px 폭에서 모두 깨지지 않게 한다(가로 스크롤 금지). 내용이 넘치면 오른쪽 영역 안에서만 세로 스크롤한다.
4. **시안의 개성을 유지한다.** 맡은 시안의 휴대폰 버전 특징(아래 시안별 지시)을 넓은 화면에서도 알아볼 수 있어야 한다. 다른 시안과 배치가 비슷하면 안 된다.
5. 색·글꼴·아이콘은 휴대폰 시안과 똑같이: 바탕 `#f2f4f6`, 카드 흰색, 파랑 `#3182f6`, 글자 `#191f28`, 보조 `#4e5968 #6b7684 #8b95a1`, 구분선 `#e5e8eb`, 빨강 `#f04452`, 노랑 띠 `#fff4e5`/`#b25e00`. Noto Sans KR + Inter(숫자, `.num` 클래스, tabular-nums). 선 아이콘 SVG(stroke 1.8~2), 이모지 금지.
6. 휴대폰 시안 파일처럼 한 파일 안에 HTML·CSS를 모두 넣는다(인라인 스타일이나 `<style>` 모두 가능). 외부 파일은 Google Fonts 링크만 허용한다. 자바스크립트는 [보기]/[숨기기] 같은 아주 간단한 토글만 쓴다.
7. 파일 맨 위 `<head>`에 `<title>시안 <시안> 넓은 화면 <화면이름></title>`와 주석 `<!-- 디자인 시안(정적 목업). 실제 앱 코드가 아님. 예시 데이터만 들어 있음. -->`.

## 예시 데이터 (휴대폰 시안과 같게)
- 가게: 우리분식 본점, 사장 김사장, 오늘 2026년 11월 23일 월요일 09:41
- 알바생: 홍길동(09:00 출근, 근무 중), 김철수(출근 전, 보건증 만료 5일 전), 이영희(08:02 퇴근, 새벽 근무, 11.20 퇴근 확인 필요), 박민수(휴무), 최지은(출근 전)
- 홍길동 11월: 1~3주 월~금 근무(시각은 휴대폰 `_Pay` 파일과 같게), 11일은 식대 없음, 23일 09:00 근무 중. 16일·120h·식대 14회, 1~3주 각 40h·주휴 O, 4주 진행 중. 시급 10,320원, 3.3%.
- 줄 돈은 기본 `●●●,●●●원`으로 숨기고 [보기]를 누르면 `1,437,040원`이 보이고 [숨기기]로 다시 숨긴다.
- 위생 점검: 8개 분류(식재료·조리 기본 3/3, 개인위생 3/5, 이물 관리 2/2, 원재료 보관·관리 8/8, 온도 관리 3/3, 소도구·화학제품 2/2, 주방 청결 6/10, 매장·외부·방충 0/5), 진행 27/38, 점검 필요 1개, 냉장 3.0°C, 냉동 −20.0°C. 항목 문장은 휴대폰 `_Chk` 파일과 `src/checklist.js`에서 가져온다.
- 계좌: 예시은행 1234-56-789012, 예금주 우리분식.

## 화면별 꼭 들어갈 것
- 출퇴근(`_Punch`): 시계·날짜, 알바생 목록과 출근/퇴근, 비밀번호 입력 방식, 모두 퇴근, 계좌이체 QR 버튼, 관리자 버튼, English(언어) 버튼.
- 근무·급여(`_Pay`): 알바생 선택, 월 이동, **달력 칸 안에 일자·출근·퇴근·식대 여부**, 주차별 요약(근무일 수·시간·식대 횟수·주휴), 줄 돈 숨김/보기, 퇴근 확인 필요 알림, 명세서·내보내기(엑셀·PDF·카톡) 진입. 넓은 화면이므로 달력 칸을 크게 해서 글자를 휴대폰보다 읽기 쉽게 한다.
- 위생 점검(`_Chk`): 점검일·점검자, 온도(냉장·냉동), 8개 분류와 진행도, 항목별 적합/점검 필요, 보건증 경고, 메모, 보관함에 저장, 지난 점검 보관함 진입.
- 계좌이체 QR(`_QR`): 큰 QR(가짜 무늬로 그린다), 가게명, 계좌·예금주, 계좌번호 복사, 안내판 인쇄, 닫기. 태블릿을 계산대에 세워 두고 손님이 찍는 상황.
- 설정(`_Set`): 휴대폰 `_Set` 파일과 FEATURES.md의 설정 항목 전부. 넓은 화면에서는 왼쪽 분류 목록 + 오른쪽 상세처럼 두 단으로 짜도 된다.

## 완료 조건
- 5장이 모두 있고, 브라우저로 1180×820과 1440×900에서 열었을 때 가로 스크롤 없이 보인다.
- 왼쪽 메뉴로 같은 시안의 화면끼리 이동된다.
- 휴대폰 시안에 있던 기능·정보가 하나도 빠지지 않았다.
