# 시안 I 맞추기 2 — 위생 점검 화면

먼저 `docs/design/briefs/matchI_common.md`를 읽고 그 규칙을 모두 따른다.
기준: 휴대폰 `docs/design/mockups/I_Chk.html`, 넓은 화면 `docs/design/mockups/wide/I_Chk.html`.

## 지금 앱과 시안의 차이 (Claude가 화면을 비교해 찾은 것)
지금 앱(390px)은 위에서부터: 공통 머리띠 → "점검 정보" 입력 카드(매장명 읽기 전용 칸 + [설정에서 바꾸기], 점검일자 칸, 점검자 칸, 냉장·냉동 온도 칸과 적정 안내,
[전체 적합으로 체크][전체 해제] 버튼과 "N / 41 체크", 긴 안내 문장) → 분류 접기 목록 → 특이사항 메모 → 오른쪽(아래)에 점검표 미리보기 문서 → 보관함.

시안 I_Chk는 위에서부터:
1. 머리 줄: 왼쪽 **"위생 점검"**, 오른쪽 **보관함 아이콘**(지난 점검 보관함 열기)·**⋯**
2. **정보 카드 하나**(2×2 칸): "점검일 · 점검자 / 11.23 · 김사장", "진행 / 27 / 38 · 필요 1(빨강)", "냉장 0~5°C / 3.0°C", "냉동 −18°C 이하 / −20.0°C"
   — 값을 누르면 바로 고칠 수 있게(지금 입력 칸 `#cDate`·`#cInspector`·`#cFridge`·`#cFreezer`를 이 카드 안 모양으로)
3. 분류 접기 목록: 다 맞은 분류는 접혀서 "식재료·조리 기본 3/3"(초록), 점검 필요가 있는 분류는 펼쳐서 항목과 [적합][점검 필요] — 이건 이미 비슷하다(유지)
4. **화면 아래 고정 바**: 왼쪽 작은 버튼 두 개(✓ = 전체 적합, 메모/미리보기 아이콘), 오른쪽 큰 파란 **[보관함에 저장]**
- 매장명은 시안에 없다 → 정보 카드에서 빼고 점검표 미리보기·인쇄에는 그대로 나오게(설정의 매장 정보 값).

## 해야 할 것
- 위 1~4 모양으로 바꾼다. 특이사항 메모(`#cMemo`), 전체 해제(`#btnCheckNone`), 점검표 미리보기(`#chkDoc`)·인쇄·엑셀, 보관함 목록·삭제·비우기는
  아래 바의 버튼·⋯ 더보기·보관함 아이콘에서 열리게 옮긴다(사라지면 안 됨).
- 아래 고정 바는 휴대폰 아래 메뉴 위에 붙게(근무·급여의 줄 돈 바처럼), 넓은 화면에서는 점검 칸 아래에.
- 넓은 화면(1024px 이상): `wide/I_Chk.html`처럼 왼쪽 분류 목록(진행) + 오른쪽 펼친 분류 항목, 위에 온도 카드.
