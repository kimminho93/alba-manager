# 시안 I 맞추기 1 — 근무·급여 고칠 점 (Claude 화면 검토 결과)

먼저 `docs/design/briefs/matchI_common.md` 규칙을 따른다. 방금 네가 만든 근무·급여 화면을 시안과 나란히 비교했다.
대부분 시안과 같다(이름 ▾·종·⋯, 달력, 주차 줄, 막대, ⋯ 메뉴·이름 ▾ 메뉴에 기능이 잘 옮겨짐). **다른 점 2개만** 고친다. 다른 곳은 건드리지 않는다.

1. **둘째 줄 좌우 순서가 반대다.**
   - 시안 `I_Pay.html`: 왼쪽 **‹ 2026년 11월 ›**, 오른쪽 작은 요약 **"16일 · 120h · 식대 14"**
   - 지금: 왼쪽 요약 "9일 · 45h · 식대 9", 오른쪽 ‹ 2026년 11월 ›
   → 시안처럼 달 이동을 왼쪽, 요약을 오른쪽으로.

2. **줄 돈 바 위치가 다르다.**
   - 시안(휴대폰): 줄 돈 바 "11월 줄 돈 / ●●●,●●●원 / [보기]"가 **화면 맨 아래, 아래 메뉴 바로 위에 붙어 있다**(스크롤해도 늘 보임).
     지금은 머리 줄 바로 아래(달력 위)에 있고 스크롤하면 사라진다.
   - 시안(넓은 화면 `wide/I_Pay.html`): 줄 돈 바가 **가운데 달력 칸의 맨 아래**에 있다. 지금은 달력 칸 맨 위에 있다.
   → 휴대폰은 아래 메뉴 위에 고정(position: sticky 또는 fixed, 아래 메뉴 높이 + 안전 영역만큼 띄움, 본문 끝이 바에 가리지 않게 여백),
     넓은 화면은 달력 칸 맨 아래에 붙게(sticky bottom). [보기]를 누르면 펼쳐지는 명세서·카톡·PDF·엑셀 줄도 바와 함께 아래에서 펼쳐진다.
   - 잠긴 매장 기기·알바생 0명일 때는 바가 보이지 않아야 한다(지금처럼).

고친 뒤 테스트(공통 규칙 9번)를 다시 돌리고, `web/index.html`의 `?v=` 7개를 새 숫자로 올린다. 커밋·푸시는 하지 않는다.
