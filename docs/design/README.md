# UI 시안 — Claude Code 적용 안내

새 UI 시안(I~M)을 저장소 안에 정적 HTML로 옮겨 둔 폴더다.
Claude Code는 이 파일들을 직접 열어 보고, 비교하고, `web/`에 옮겨 적용할 수 있다.

- 원본 캔버스: https://claude.ai/artifact/MBtD999uf7nwsM5gdRyqJ8 (A~H 이전 시안까지 모두 있음)
- 이 폴더에는 **기능 목록 기준으로 만든 최신 시안 I~M만** 옮겼다 (2026-11-28).
- `docs/`는 GitHub Pages에 올라가지 않는다(배포되는 건 `web/`뿐). 시안 파일을 고쳐도 실제 앱에는 영향이 없다.

## 상태

- **시안 I로 확정했다(2026-11-28).** 휴대폰 `mockups/I_*.html`, 태블릿 가로·PC `mockups/wide/I_*.html`. 패치 계획은 `docs/design/PATCH_PLAN_I.md`.
- 색감은 시안 A(토스 클린)로 확정됐다. I~M은 모두 이 색감을 쓴다.
- 하단 메뉴 4개(출퇴근 / 근무·급여 / 위생 점검 / 설정), QR은 출퇴근 화면 버튼과 설정에서 전체 화면으로 연다.
- 결정 사항 전체는 루트 `CLAUDE.md`와 `docs/FEATURES.md`의 "새 UI 배치표"를 따른다.

## 보는 방법

- 모아 보기: `docs/design/mockups/index.html`을 브라우저로 연다 (시안마다 6장이 한 줄).
- 한 장씩: `docs/design/mockups/<시안>_<화면>.html`. 폭 390px에 맞춰져 있다.
- Claude Code에서 화면을 확인할 때는 Playwright 등으로 390×844 크기 스크린샷을 찍어 본다.
- **넓은 화면(태블릿 가로 1180×820 · PC 1440×900) 버전**: `docs/design/mockups/wide/index.html`에서 모아 본다(위쪽 버튼으로 크기 전환). 파일 이름 규칙은 같고 손님 화면(`_Cust`)만 없다. 왼쪽 세로 메뉴가 1300px 미만에서는 88px(아이콘 위주), 이상에서는 220px(글자 포함)이다.
- 넓은 화면 시안은 제미나이(안티그래비티 `agy`)가 `docs/design/briefs/`의 지시서로 만들고 Claude가 검토했다(2026-11-28).

| 파일 이름 뒤쪽 | 화면 | 기능 목록 번호 |
|---|---|---|
| `_Punch` | 출퇴근 (매장 기기) | 1-1 ~ 1-10, 0-1, 0-7 |
| `_Pay` | 근무·급여 (달력 + 주차 요약 + 숨긴 줄 돈) | 2-1 ~ 2-23 |
| `_Chk` | 위생 점검 | 3-1 ~ 3-11 |
| `_QR` | 계좌이체 QR (전체 화면) | 4-2, 4-3 |
| `_Set` | 설정 | 5-1 ~ 5-13, 0-3, 0-5 |
| `_Cust` | 손님 화면 (`web/pay.html`) | 4-4 |

## 시안 요약

| 시안 | 근무·급여 달력 | 출퇴근 | 위생 점검 | 특징 |
|---|---|---|---|---|
| I · 주차 줄 달력 + 금액 바 | 칸 안에 날짜·출근·퇴근, 칸 아래 파란 막대 = 식대, 주마다 요약 줄 | 이름 줄 + 버튼 | 묶음 접기/펼치기, 항목마다 [적합 \| 점검 필요] | 줄 돈은 화면 아래 고정 바(숨김→보기), 퇴근 확인 필요는 노란 띠 |
| J · 주차 탭 달력 + 2단계 출퇴근 | 주차 탭으로 주 선택 → 달력 강조 + 요약 줄, 칸 안 ↑출근 ↓퇴근 "식" | 이름 → 비밀번호 → 큰 버튼 | 분류 칩 + 항목 카드마다 큰 O / X | 줄 돈·명세서는 하단 고정 |
| K · 주 카드 달력 + 떠 있는 메뉴 | 주마다 카드 한 장(머리에 주차 요약, 안에 7칸) | 큰 타일 + QR·모두 퇴근 타일 | 온도 카드 + 체크 목록 + 떠 있는 진행/저장 바 | 떠 있는 하단 메뉴, 설정은 빠른 버튼 4개 |
| L · 큰 칸 달력 + 주 요약 열 | 큰 칸(출퇴근 12px) + 식대 칩, 왼쪽 검은 열 = 주차 요약 | 원형 이름 3열 → 비밀번호 키패드 시트 | 종이 점검표 같은 두 열 표 | 가독성 가장 좋음 |
| M · 요약 대시보드 + 주차 표 | 위에 이번 달 시간 크게, 파란 블록 달력(점 = 식대), 아래 1~5주 표 | 근무 중 / 출근 전 묶음 | 진행 도넛 + 분류 8개 타일 | QR 화면에 손님 휴대폰 미리보기 |

## 디자인 기준값 (시안 공통)

실제 앱 `web/style.css`의 `:root` 변수(현재 `--bg #f3f5fa`, `--primary #3563f0` 등)를 아래 값으로 옮기는 것부터 시작한다. 다크 모드 값도 같이 맞춘다.

| 용도 | 값 |
|---|---|
| 바탕 | `#f2f4f6` |
| 카드 | `#ffffff` |
| 본문 글자 | `#191f28` |
| 보조 글자 | `#4e5968`, `#6b7684`, `#8b95a1` |
| 흐린 글자·비활성 메뉴 | `#b0b8c1` |
| 구분선 | `#e5e8eb` |
| 주색(파랑) | `#3182f6`, 눌림/진한 파랑 `#1b64da`, 연한 파랑 바탕 `#e8f3ff` |
| 경고(빨강) | `#f04452` |
| 주의(노랑 띠) | 바탕 `#fff4e5`, 글자 `#b25e00` |
| 글꼴 | 시안은 Noto Sans KR + Inter(숫자, `tabular-nums`). 실제 앱은 Pretendard를 쓰면 더 토스에 가깝다 |
| 카드 모서리 | 18~24px |
| 아이콘 | 이모지 대신 선 아이콘(SVG, stroke 1.8~2) |

## 시안을 실제 앱에 옮길 때 지킬 것

1. 시안은 **화면 모양만** 참고한다. 숫자·이름은 예시다. 실제 값은 `web/app.js`·`web/engine.js`가 계산한 것을 그대로 쓴다.
2. 시안 HTML은 인라인 스타일로 되어 있다. 그대로 붙여 넣지 말고 `web/style.css`의 클래스와 변수로 다시 쓴다.
3. `docs/FEATURES.md`의 기능이 하나라도 빠지면 안 된다. 바꾸기 전과 후에 표를 하나씩 대조한다.
4. 한 번에 다 바꾸지 말고 화면 하나씩 나눠 커밋한다. 권장 순서: 색·글꼴 변수 → 하단 메뉴 4개 → 출퇴근 → 근무·급여 → 위생 점검 → 설정 → QR·손님 화면.
5. 화면마다 390px 폭과 데스크톱 폭, 한국어·영어, 라이트·다크 모드를 확인한다. PC 화면은 폰을 늘린 모양이 아니라 옆 공간을 쓰는 배치(왼쪽 요약·명단 + 오른쪽 달력)를 유지한다.
6. 배포 전에는 `/ship-check` 순서를 따른다. 화면이 바뀌면 사용 방법 가이드 스크린샷(`web/img/guide-*.webp`)도 새로 찍는다.

## Claude Code에 이렇게 요청하면 된다 (예시)

- `docs/design/mockups 의 I~M 시안을 스크린샷으로 비교해서 FEATURES.md 기준으로 빠진 기능이 있는지 표로 정리해 줘`
- `근무·급여 화면은 L, 출퇴근은 J로 섞기로 했어. CLAUDE.md의 UI 방향을 이 결정으로 고쳐 줘`
- `1단계로 web/style.css 색 변수를 docs/design/README.md 기준값으로 바꾸고, 다크 모드도 맞춘 뒤 테스트해 줘`
- `출퇴근 화면을 시안 J_Punch 모양으로 바꿔 줘. 기존 기능(1-1~1-10)은 그대로 두고 390px·데스크톱 스크린샷으로 보여 줘`
