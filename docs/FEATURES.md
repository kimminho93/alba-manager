# 사장님 도우미 — 전체 기능 목록 (v1.7.1 기준)

UI를 새로 짤 때 **이 목록의 모든 기능이 새 화면 어딘가에 들어가 있어야 한다.**
시안을 만들거나 패치할 때 맨 아래 "새 UI 배치표"에서 빠진 칸이 없는지 먼저 확인한다.
기능을 추가하거나 없애면 이 파일도 같이 고친다.

조사 근거: `web/index.html`, `web/app.js`, `web/engine.js`, `web/gsync.js`, `web/pay.html` (2026-11-24, 커밋 cb23272)

## 새 UI 배치표 (초안, 시안 확정 전)

새 화면 구성을 **하단 메뉴 4개 + 따로 여는 화면**으로 잡는다. 시안마다 아래 칸이 모두 채워져야 한다.

| 새 화면 | 들어갈 기능 |
|---|---|
| **출퇴근** (하단 메뉴) | 1-1 ~ 1-10, 0-1 관리자 잠금 버튼, QR 열기 버튼, English |
| **근무·급여** (하단 메뉴) | 2-1 ~ 2-23 (2-17 시간표는 달력에 합침). 맨 위: 알바생 고르기, 달, 줄 돈(숨김). 가운데: 달력(칸 안에 날짜·출근·퇴근·식대) + 주차 요약. 아래 또는 ⋯: 명세서, 카톡 복사, PDF, 엑셀, 정산 설정 |
| **위생 점검** (하단 메뉴) | 3-1 ~ 3-11 |
| **설정** (하단 메뉴) | 5-1 ~ 5-13, 0-3 구글 시트 연결, 0-5 사용 방법(가이드 전체) |
| QR 화면 (전체 화면으로 열림) | 4-2. 출퇴근 화면과 설정에서 열기 |
| 알림 (종 아이콘 → 시트) | 0-2 보건증 알림, 1-10 퇴근 확인 필요, 0-4 수정 충돌 |
| 날짜 편집 시트 | 2-13 ~ 2-16 |
| 알바생 편집 시트 | 2-2, 2-4, 2-6 ~ 2-10 |

### 정한 것 (2026-11-24)
- 하단 메뉴는 4개: 출퇴근 / 근무·급여 / 위생 점검 / 설정. QR은 하단 메뉴에 넣지 않고, 출퇴근 화면 버튼(과 설정)에서 전체 화면으로 연다.
- 사용 방법(가이드)은 설정 안으로 옮긴다. 알바생이 없을 때 첫 화면(2-1)에도 링크를 둔다. 상단 ? 버튼은 없앤다.
- 출퇴근 시간표 보기(2-17)는 달력에 합친다. 달력 칸에 시간이 다 보이므로 날짜를 눌러 수정하고, 시간표 보기 전환은 없앤다.
