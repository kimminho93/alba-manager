# 🧾 사장님 도우미 (Alba Manager)

GitHub Pages(정적 호스팅)에서 **별도 백엔드 서버 없이도 100% 동작**하는 알바 급여·주휴수당·식대 정산 & 매장 위생 점검표 웹 애플리케이션입니다.

## ✨ 주요 기능

### 1. 💰 1초 알바 급여 & 표준 급여명세서
- **한 줄 자연어 파서**: `"지민 평일 5시간 시급 10,500원 4시간 이상 식대 8,000원"`, `"철수 이번 달 총 62시간, 시급 10,000원 지각 20분"` 등 한글 시급·근무시간·식대·지각 자동 인식
- **3가지 근무시간 입력 방식**:
  - 📅 **매일(일별) 시간 입력**: 4주 × 7요일(28칸) 시간표 + 평일/주말 일괄 채우기
  - 📆 **주차별(1~4주) 시간 입력**
  - ⏱ **월 총 시간 입력 (4주 균등 분할)**
- **주휴수당 & 식대 자동 정산**:
  - 주 15시간 이상 근무 주에 대해 `(min(주시간, 40) / 40) × 8 × 시급` 자동 계산 (체크/해제 즉시 반영)
  - 하루 일정 시간(예: 4시간) 이상 근무한 날에 대해 1일 식대 자동 합산
- **세금 공제 (10원 미만 절사)**: `3.3% 사업소득세`, `4대보험`, `미적용(0%)`
- **출력 및 공유**: 카카오톡 명세서 복사, A4 PDF 인쇄(`@media print`), 외부 라이브러리 없는 순수 JS `.xlsx` 엑셀 다운로드, 다중 알바생 정산 명단 합산

### 2. 🧼 매장 위생 점검표
- 냉장(0~5°C) / 냉동(-18°C 이하) 온도 기준 판정 및 3대 핵심 체크박스 연동
- 개인위생·이물·원재료 보관·온도·주방/매장 청결·서류 등 **위생 점검 41개 항목** 체크 → 적합/점검필요 실시간 자동 판정
- 점검표 PDF 인쇄, `.xlsx` 엑셀 다운로드, 일별 점검 보관함 누적 및 일괄 엑셀 다운로드

## 🚀 로컬 실행 방법

```bash
# 1. 웹/엔진 번들 빌드 및 테스트
node tools/build.js
node tests/test_main.js
node tests/test_server.js

# 2. 로컬 서버 실행 (http://localhost:8000)
node server/app.js
```
또는 서버 없이 `web/index.html` 파일을 브라우저에서 바로 열어도 100% 동일하게 동작합니다.
