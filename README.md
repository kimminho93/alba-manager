# 🧾 사장님 도우미 (Alba Manager)

자영업 사장님을 위한 웹 도구입니다. **알바 급여 정산**(주휴수당·식대·세금)과 **매장 위생 점검표**를 휴대폰·PC 브라우저에서 바로 쓸 수 있습니다.
회원가입이나 서버 없이 브라우저만으로 동작합니다. 입력한 내용은 기본적으로 내 기기에만 저장되고, 원하면 내 구글 드라이브의 스프레드시트에도 자동 저장할 수 있습니다.

- 접속: <https://kimminho93.github.io/alba-manager/>
- 대상: 글씨가 크고 단순한 화면이 필요한 사장님. 상단의 `가+` 버튼으로 글자를 더 크게 볼 수 있고, 🌙 버튼으로 어두운 화면으로 바꿀 수 있습니다.

## ✨ 기능

### 💰 급여 계산
| 기능 | 설명 |
| --- | --- |
| 근무 입력 | 7칸 달력(폰 세로에서도 한 화면)에서 날짜를 누르면 팝업(폰은 아래에서 올라오는 시트)이 열려 시간·식대·휴게시간·휴무를 정합니다. 팝업 안 '여러 날 한꺼번에 적용'으로 평일/주말/같은 요일 일괄 입력, 주별 합계·주휴는 한 줄 요약 |
| 빠른 시간대 | 자주 쓰는 근무시간을 최대 20개까지 직접 만들어 저장 (예: 오전 09:00~14:00) |
| 지급월 | ◀ ▶ 버튼으로 월 이동. 해당 월의 실제 달력과 주차가 자동 반영 |
| 주휴수당 | 한 주 15시간 이상 근무하고, 약속한 출근일수를 채운 주에만 지급 (아래 규칙 참고) |
| 식대 | 기준시간(기본 4시간) 이상 근무 + 점심(11~14시)·저녁(17~20시) 시간대와 1시간 이상 겹치면 **끼니별(회)** 자동 체크. 풀타임은 2회. 달력에서 점심/저녁 체크박스로 직접 수정, 시간대는 ⚙️ 설정, 1회 금액은 직접 설정 |
| 세금 | 3.3% / 4대보험 / 미적용 선택 (10원 미만 절사). 소득세·지방소득세·국민연금·건강보험·장기요양·고용보험 비율과 최저시급은 `⚙️ 설정` 탭에서 수정 (구글 저장·백업 파일에 포함) |
| 출퇴근 찍기 | 매장 공용 기기에서 알바생이 이름 → 비밀번호로 출근/퇴근을 찍음(찍힌 시각 그대로 달력에 반영, 결과 팝업 5초). 관리자 비밀번호를 정하면 평소엔 출퇴근 화면만 보이고 나머지 탭은 잠김(10분 무입력 시 자동 잠금). 시트 `출퇴근기록` 탭에 한 줄씩 기록. 관리자 비밀번호는 첫 안내(또는 설정)에서 정하고, 사본이 시트 `관리자` 탭 B1에 저장되어 잊었을 때 B1을 고친 뒤 잠금 창의 [비밀번호를 잊었어요]로 복구 |
| 출력·공유 | 카카오톡용 명세서 복사, A4 PDF 인쇄/저장, 엑셀(.xlsx) 다운로드 |
| 알바생 명단 | 이름·계약서상 주 근무일·시급으로 알바생을 등록하면, 이름을 눌러 그 사람의 달별 근무 기록을 달력에서 보고 고칠 수 있음(고치면 자동 저장). 기록 없는 달은 빈 달력(0원), 시급 변경은 선택한 달부터 적용, 엑셀은 받을 사람을 골라 체크한 사람의 모든 달을 한 파일로 |

**주휴수당 규칙**
- 주 15시간 이상 근무한 주만 대상입니다.
- 주 근무 약속일수(기본 5일)보다 적게 출근한 주는 주휴수당이 없습니다. 사정이 인정되는 주는 달력에서 예외로 체크할 수 있습니다.
- 월 경계에 걸친 주(그 달 안의 날이 7일 미만인 주)는 출근일수 검사를 하지 않습니다.
- 금액은 `(min(주 근무시간, 40) ÷ 40) × 8 × 시급` 입니다.

**급여 엑셀 구성**
- 알바생 1명: `요약` / `급여명세서` / `출퇴근 기록` / `주차별 요약` 탭
- 정산 명단(여러 명): `전체 요약` + 월별 `정산` / `근무기록` / `주휴판정` 탭. 사람이 늘어도 탭 수는 늘지 않고, 근무기록 탭에는 사람별 누적 근무일수·근무시간이 표시됩니다.

### 🧼 위생 점검
- 매장 위생 점검 **41개 항목**을 9개 분류(식재료·조리 기본, 개인위생, 이물 관리, 원재료 보관·관리, 온도 관리, 소도구·화학제품, 주방 청결, 매장·외부·방충, 교육·게시물·서류)로 나누어 점검
- 문제없는 항목만 체크하면, 체크하지 않은 항목은 `점검필요(X)`로 표시. `전체 적합으로 체크` 버튼 제공
- 냉장(0~5°C)·냉동(-18°C 이하) 온도를 입력하면 20번 항목(냉장·냉동고 온도)에 기준 이탈 여부가 반영됩니다
- 점검표 PDF 인쇄, 엑셀 다운로드, **일별 보관함**에 저장해 두고 한꺼번에 엑셀로 내려받기

### ☁️ 구글 시트 자동 저장 (선택)
- 화면 위쪽 `☁️ 구글 저장` 버튼 → `구글 계정으로 연동하기`를 누르고 로그인·허용만 하면 끝입니다. API 키 같은 건 입력하지 않습니다.
- 내 구글 드라이브에 **"사장님 도우미 데이터"** 스프레드시트가 자동으로 만들어지고, 알바생 기록·점검 보관함·빠른 시간대·매장 정보가 저장됩니다.
  - `2026-11` 같은 **월별 탭**: 그 달 정산 요약 + 날짜별 근무 기록 (바뀐 달만 다시 씀). 5년(60개월)이 지난 달 탭은 시트에서만 자동 삭제하며, 앱·기기·백업 파일의 기록은 지우지 않습니다.
  - `알바생`, `점검 보관함` 탭: 보기 쉬운 표 (앱이 자동으로 다시 씀). `알바생` 탭에는 알바생마다 자동으로 붙는 **고유코드**(8자리)가 들어 있습니다.
  - `출퇴근기록` 탭: 나중에 출퇴근(QR) 프로그램이 한 줄씩 추가할 자리. 앱은 머리글(기록시각·알바생 고유코드·이름·구분·입력방식·메모)만 만들고 그 뒤로는 **지우거나 덮어쓰지 않습니다**.
  - 시트에서 직접 고친 내용은 앱으로 다시 읽지 않습니다 (시트는 저장·열람·이동용)
  - `데이터` 탭: 앱이 읽는 원본 (수정하지 마세요)
- 내용을 바꾸면 3초 뒤 자동 저장되고, `지금 저장`, `시트에서 다시 불러오기`, `연동 끊기` 버튼이 있습니다. 다른 기기에서 같은 계정으로 연동하면 같은 기록을 볼 수 있습니다.
- 권한은 `drive.file` 하나뿐이라 **이 앱이 만든 파일만** 접근하고, 데이터는 브라우저에서 구글로 바로 저장됩니다(개발자 서버 없음). 연동을 켜기 전에는 구글로 아무것도 전송되지 않습니다.
- 여러 기기에서 동시에 고치면 마지막에 저장한 내용이 남습니다. 구글 로그인은 1시간마다 갱신되며, 브라우저에 따라 가끔 `다시 연결` 버튼을 눌러야 할 수 있습니다.
- **백업 파일**: 연동 창 아래쪽의 `백업 파일 내려받기`로 모든 기록을 파일 하나(.json)로 저장하고, `백업 파일 불러오기`로 복원합니다. 구글 계정을 바꾸거나 다른 기기로 옮길 때, 구글 연동 없이 쓸 때의 백업으로 쓸 수 있습니다. 불러오면 현재 기록은 파일 내용으로 바뀌며(확인창 표시), 구글 연동 중이면 시트에도 자동 반영됩니다.
- 구글 클라우드의 OAuth 클라이언트 ID는 `web/gsync.js` 맨 위에 있습니다(공개되어도 되는 값). 승인된 JavaScript 출처에 접속 주소(`https://kimminho93.github.io`)가 등록되어 있어야 합니다.

## 🛠 개발

순수 JavaScript로 만들어졌고 외부 패키지가 필요 없습니다. (Node.js 18 이상 권장)

```bash
npm run build   # src/*.js 를 web/engine.js 로 묶기 (수정 후 반드시 실행하고 함께 커밋)
npm test        # 단위 테스트 + 구글 연동 로직 테스트 + 서버 통합 테스트
npm start       # 로컬 서버 http://localhost:8000
```

`web/index.html` 파일을 브라우저에서 바로 열어도 동작합니다. Windows는 `run.bat`을 실행하면 됩니다.

### 폴더 구조
```
web/        화면 (index.html, app.js, style.css), 구글 연동(gsync.js), 빌드된 engine.js
src/        계산 엔진: payroll(급여·주휴·식대), checklist(위생 점검), backup(백업 파일), reports·xlsx(엑셀 생성), parser, stats, math_ops
server/     선택 사항인 로컬 API 서버 (같은 엔진 사용)
include/    Node에서 엔진을 불러오는 진입점
tools/      build.js (엔진 번들러)
tests/      test_main.js, test_cloud.js, test_server.js
```

### 배포
`main` 브랜치에 푸시하면 GitHub Actions(`.github/workflows/pages.yml`)가 자동으로 GitHub Pages에 배포합니다.

### 참고
- 계산 결과는 참고용입니다. 실제 신고·납부는 세무 전문가 또는 관할 기관 기준을 확인하세요.
- 데이터(빠른 시간대, 알바생 기록, 점검 보관함)는 브라우저 저장소에 보관되므로, 브라우저 데이터를 지우면 함께 사라집니다. 구글 연동을 켜 두었다면 시트에서 다시 불러올 수 있습니다.
